# 数字乡村政策：时间演变、区域差异与敏感性分析（ICU探索性）

输入为 `policy_topics_icu_pilot.zip` 的 `document_theme_scores.csv`、`strict_document_scores.csv` 和 `metadata_snapshot.tsv`。读取后校验59份文档、每文档7类主题、两套分词结果及严格词典得分；重新核算命中密度及核对元数据。不重新执行分词或独立人工标注。来源为 GitHub `policy_topics` 阶段（提交 eec51561c471e84d1cd53744564668a0ae06540d）；逐篇主题分数来源于此前完整本地结果包。

## 方法
- 指标：每万保留词主题词命中次数。中央按政策等权；省级先按同一省份政策等权平均，再对区域内省份等权平均。
- 时间：17份中央政策按年汇总；另独立比较2022—2025年四份同名年度工作要点。每年仅一份同类文本，不作显著性检验。
- 区域：全部42份省级政策覆盖29省；排除10份数字产业与流通专项后剩32份覆盖22省。为区分政策类型与地区覆盖，另比较固定22省的35份原样本与32份非产业流通专项样本。仅数字农业与信息化19份（17省）、仅综合性数字乡村8份（8省）分别输出；由于东北同类型只剩一省，不宜外推。
- 词典敏感性：基础词典与排除41个歧义词的严格词典采用相同基础分词分母；探索停用词方案的分母不同，需另行解释。不同主题的词典覆盖不同，不能直接解释为真实主题占比。
- 省际相似度：29省的七维平均主题密度向量余弦相似度，不反映政策扩散因果，不是政策成效排名。

## 主要探索性观察
- 2024年全中央样本智慧农业密度239.4，同年年度工作要点98.1。2022—2025年同类型工作要点智慧农业67.9、119.9、98.1、106.8；严格词典49.8、82.7、71.7、65.0，末年高于首年，但不是单调上升。
- 西部产业流通密度：全12省332.0，固定有非产业流通样本的6省原样本122.7，固定6省排除专项后112.7。说明样本覆盖和政策类型影响区域比较，不能将原始差异归因为区域偏好。
- 仍缺天津、海南；2020—2021中央样本类型不均衡，东北样本很少。词典尚未完成人工验证，Jieba尚未正式重跑。以上不是最终结论。

## 复现
Python 3；依赖 numpy、pandas、scipy、matplotlib 及中文字体（建议 Noto CJK 或微软雅黑）。
`python analyze_results.py --input input/policy_topics --out .`
`figures/` 包含9图的PNG和SVG；`tables/`包含对应数值及分组敏感性分析；输入文件为精简上轮结果。未包含字体文件。
