# 数字乡村政策研究：聚类、敏感性与语境复核（探索版）

基于已存档的59份V2政策ICU试验分词主题指标，不重新收集政策，不更改原始语料或旧图数据。`redrawn` 为此前9张图的低饱和浅色重绘版，13张CSV结果表与上一轮逐字节一致；新增4图和6张分析CSV。图表采用统一配色、不同线型标记或同一渐变色标，数据未修改。

聚类：各省政策先等权汇总为七维主题命中密度向量，再L2归一化；K-means以欧氏距离对比K=2—6，n_init=20，5个随机种子，基础方案按平均轮廓系数选择K=2，展示seed=42。五个方案共125次聚类；ARI比较同一省份集合的分组，不代表现实发展模式。全29省的8/21分组对词典宽严与停用词稳定（ARI=1），但与固定22省重新拟合结果ARI=-0.015；固定22省排除前后ARI=1。说明分组结构高度依赖省份覆盖，不代表删除专项文本本身导致所有变化。层次聚类仅作辅助展示。

逐省剔除敏感性：每次剔除某区域一个省份后重算区域平均，报告最小—最大值，不是置信区间。2022—2025同类型中央工作要点比较三种评分设置。严格词典下智慧农业2022年49.8、2025年65.0，基础词典为67.9、106.8，两者均为2025高于2022；四年波动，不能说逐年上升。

语境复核：从上一轮358条已保留的分词上下文中，每个主题分别抽取3条严格词典保留词与3条严格词典排除词（组内按文件去重，seed=42），42条来自29份政策；模型辅助复核判定支持29条、不支持7条、待定6条。由于不是从全部命中随机抽样、上下文是过滤后的词序而非原始段落、且没有独立人工复核，不能当作准确率/召回率或正式人工编码。context_audit_42.csv保留人工复核空列；应核对原文、增加未命中片段及独立编码，再修正词典并重新运行所有指标。正式Jieba未执行；原有来源核验局限仍存在。

运行：`python validate.py --input /path/to/policy_topics --out /path/to/output`；`python redraw_results.py --input /path/to/policy_topics --out /path/to/output`；`python sample_contexts.py --input /path/to/policy_topics/pilot_icu --output audit_sample.csv`。依赖 numpy、pandas、scipy、scikit-learn、matplotlib、cycler；需安装可显示中文的字体。输入主题指标见上一轮 policy_topics_icu_pilot.zip；本包也提供所需输入。不要将探索性图表当作正式论文定稿。
