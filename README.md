# 数字乡村政策研究资料

本仓库发布当前已整理的清洗语料包，包含 **61 份 TXT 正文/候选文本**、正文清单和核验索引。

- `01_主语料_45篇`：当前稳定主语料
- `02_辅助语料_6篇`：辅助比较样本
- `03_新增核心文本_待并入清单`：新增候选，纳入前需更新总清单并复核
- `04_扩展候选_待纳入评估`：扩展候选，暂不直接并入主模型
- `05_去重对照_不重复计数`：重复对照，不重复计数
- `06_案例与非定量参考`：案例及参考文本，不作为政策全文样本

下载压缩包后解压即可使用。`README.md` 和 `manifest.csv` 说明文件结构；manifest记录路径、大小、字符数及SHA-256。正式分析前仍需与本地既有正文进行全文去重。61份是本包文件数，不代表都应进入同一主题模型；核心主语料为45篇。
